# Проверка пунктуации: LanguageTool

Проверено по первичным источникам 2026-11-04:

- https://github.com/languagetool-org/languagetool — открытый движок с языковыми правилами.
- https://dev.languagetool.org/http-server — локальный HTTP-сервер на Java, обычно порт 8081.
- https://languagetool.org — пользовательский продукт и отдельные возможности сервиса.

LanguageTool умеет проверять грамматику и ряд правил пунктуации на русском и английском.
Даже он не гарантирует правильность всех авторских запятых. Локальные правила и платные
возможности облачного продукта не следует считать одинаковыми.

## Проверенная связка — этап 3

Системная Java не требуется. Использованы официальный архив LanguageTool **6.6**
(README требует Java 17+) и Temurin JRE **21.0.13+9 LTS**, Windows x64.
В перечне стабильных ZIP на languagetool.org/download последним был 6.6.
Версия закреплена, ночная сборка не используется.

- LanguageTool ZIP: 251 998 221 байт, SHA256
  `53600506B399BB5FFE1E4C8DEC794FD378212F14AAF38CCEF9B6F89314D11631`.
  Сумма зафиксирована с полученного официального архива для воспроизводимости.
- Temurin ZIP: 49 106 397 байт, SHA256
  `2332C0B4CFF6BED722DA3567C91D5E47568BCBA863FA4945D0A8D6FC76158628`.
  Сумма сверена с API Adoptium. Первичный ответ — `adoptium.json` в материалах.
- Полный распакованный модуль с лицензиями: 2 107 файлов, 556 903 374 байта.
  Java ограничена `-Xmx512m`; это предел heap, а не всего процесса.
- Сервер запускается без `--public`, `--allow-origin` и `--verbose`.
  Фактический сокет ручной проверки: только **127.0.0.1**. Прокси и HTTP-перенаправления
  в клиенте выключены. Тексты запросов и ответы не записываются в журнал приложения.

## Качество и задержки

Набор `qa/grammar-cases.json`: 7 ошибочных и 5 правильных примеров. Найдены ошибки
в 5 из 7 ошибочных примеров; все 5 правильных текстов прошли без замечаний.
Пропущены «Она сказала что придёт завтра» и «Мне кажется что начался дождь».
Дополнительный запрос с явно включённой PUNCTUATION эти пропуски не устранил.
Это небольшой воспроизводимый набор, а не общая оценка точности на рукописях.

Найдены, например, согласование «She go…», повтор «the the», русское несогласование
«новую книга». Варианты не всегда исправляют предложение целиком: движок предложил
«новая книга», не учитывая управление глагола «купил». Поэтому замены только ручные.

В проверке через рабочий C#-сервис первый русский запрос вместе с запуском занял
4,4 с, первое английское правило — 2,7 с; последующие короткие запросы — примерно
10–156 мс. Эти числа относятся к текущему компьютеру и небольшим примерам.
Проверены точные UTF-16-смещения после emoji, отмена, таймаут запуска, таймаут запроса,
повторный запуск и закрытие процесса. Полный отчёт — `quality-service-final.json`.

## Воспроизведение и поставка

```powershell
./tools/prepare-grammar-runtime.ps1
dotnet run --project qa/GrammarProbe/GrammarProbe.csproj -c Release -- artifacts/grammar-runtime/win-x64 qa/grammar-cases.json artifacts/grammar-quality.json
dotnet build src/ScriSelfStudio.App/ScriSelfStudio.App.csproj -c Release -p:IncludeGrammarRuntime=true
```

Первый шаг загружает закреплённые архивы и проверяет хеши. Существующий каталог
назначения не перезаписывается; для нового прогона можно задать `-Destination`.
Кеш можно задать через `-CacheDirectory`. Для нестандартного каталога при сборке
нужен `-p:GrammarRuntimeRoot=<полный путь>`. `IncludeGrammarRuntime` также поддержан
при `dotnet publish`; обычная сборка ничего не скачивает. Это локальные сборки,
стабильный установщик 1.1.13 здесь не пересобирается.

Проверена отдельная framework-dependent публикация в
`artifacts/grammar-20261104/publish-check/` (требует установленный .NET 10).
В её `Grammar/` присутствуют все 2107 файлов; SHA256 каждого совпадает с подготовленным
runtime. Отчёт — `publish-copy-report.json`. Это проверка состава публикации;
запуск живого окна выполнялся из Debug со своим профилем и тем же runtime.

Основные лицензии доступны в справке; исходные COPYRIGHT/NOTICE, COPYING,
third-party-licenses и JRE legal сохраняются внутри модуля. Java не регистрируется
в системе. Подключение — ADR 033 и IGrammarService. На других ОС модуль пока
не подготовлен и не проверен; приложение сообщает о недоступности проверки.

Материалы: `artifacts/grammar-20261104/`; runtime —
`artifacts/grammar-runtime/win-x64/`. Облачного API в реализации нет.
