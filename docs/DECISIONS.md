## Шаблон новой записи

```markdown
# ADR NNN. Короткое название

Дата: ГГГГ-ММ-ДД
Статус: предложено | принято | заменено ADR-XXX

## Контекст

## Решение

## Последствия

## Альтернативы
```

Решение, отменяющее прежнее, ссылается на заменяемый ADR и не удаляет его.
