## Шаги

1. **Модель сводки.** `RecentProjectEntry` дополнен `Description`, `BookCount`,
   `ChapterCount`, `SceneCount`, `CharacterCount`, `PlotLineCount`, `UpdatedAt`.
   Поля необязательны в JSON — старые настройки читаются без миграции.
2. **Карточка.** `RecentProjectItem` переписан: монограмма-обложка (цвет по хэшу
   имени), сводка «N книга · N глав · N сцен», дата «сегодня/вчера, HH:mm»,
   команды «Открыть», «…», «Открыть папку», «Убрать из списка».
3. **Раскладка.** `LauncherView.axaml` — сетка `228,*,336` с левой навигацией,
   центральным списком и правой панелью «Контекст проекта»; палитра — кремовая
   тема Paper.
4. **Поиск и выбор.** `VisibleProjects` фильтруется по `ProjectSearchQuery`;
   `SelectedProject` управляет правой панелью.
5. **Рамка выбранной карточки.** Обводка была почти неразличима (`#DFC0B4` на
   `#F3E3DB`). Для лаунчера выбранная карточка получила насыщенную обводку
   `ShellNavActiveBrush` (1.5px) и залитую кнопку «Открыть».
6. **Свежесть сводки (дефект).** `ProjectService.Mutate` публиковал
   `ProjectChanged` только при смене флага «грязный», поэтому после первой правки
   структуры карточка открытого проекта застревала на «1 книга · 0 глав · 0 сцен».
   Событие публикуется и при повторной правке.
7. **Подписка лаунчера (дефект).** `LauncherViewModel` зависел от
   `ShellViewModel`, который дёргал его `SyncProjectState` на каждое событие, в том
   числе автосохранение. Лаунчер подписан на шину сам, а лишний вызов из оболочки
   убран.
8. **Переживание перезапуска (дефект).** `AppPreferences.RecentProjects` был
   коллекцией только для чтения, и генератор System.Text.Json не заполнял её при
   загрузке — список последних проектов пропадал после перезапуска. Добавлен
   сеттер; покрыто тестами UiSmoke и IntegrationTests.

9. **Открытие в редакторе (дефект).** Кнопка «Открыть» открывала проект, но экран
   оставался лаунчером. Теперь после успешного открытия лаунчер открывает первую
   сцену проекта в редакторе и переводит оболочку на `AppScreen.Editor`; проект без
   сцен экран не переключает.
