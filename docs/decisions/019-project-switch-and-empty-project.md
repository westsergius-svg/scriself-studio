# ADR 019. Смена проекта и открытие пустого проекта

Дата: 2026-10-04
Статус: принято

Уточнение 2026-11-17: подготовка смены использует IWorkspaceSaveService (ADR 035),
охватывая черновики всех панелей и более новые правки во время записи.

## Контекст

Пока проект открыт, `ProjectService.CreateAsync` и `OpenAsync` возвращают ошибку
«Сначала закройте текущий проект» (инвариант «владелец один»). Из-за этого создание
или открытие второго проекта упиралось в модальный диалог ошибки, хотя пользователь
не обязан вручную закрывать предыдущий проект.

Отдельно: только что созданный проект пуст — в нём есть серия, но нет книг, глав и сцен.
`HandleLoadedProjectAsync` открывал первую сцену в редакторе, а при её отсутствии просто
выходил. Визуально ничего не происходило: экран оставался лаунчером, и проект выглядел
«неоткрытым», хотя сервис считал его открытым.

## Решение

1. **Смена проекта сохраняет и закрывает текущий.** `LauncherViewModel.PrepareProjectSwitchAsync`
   перед созданием/открытием другого проекта коммитит правки открытой сцены
   (`IEditorEngine.CommitAsync`), сохраняет проект на диск при наличии изменений
   (`IProjectService.SaveAsync`) и только потом закрывает его
   (`CloseAsync(discardChanges: false)`). Ошибка на любом шаге отменяет смену и
   показывается пользователю — данные не теряются. Помощник вызывается из
   `CreateProjectAsync`, `CloseProjectAsync` и `OpenPathAsync`.
2. **Открытие проекта всегда ведёт в рабочее пространство.** `OpenProjectWorkspaceAsync`
   после успешной загрузки показывает первую сцену в редакторе (`AppScreen.Editor`),
   если сцена есть. У только что созданного проекта сцен нет, поэтому открывается карта
   книги (`AppScreen.Architecture`) с подсказкой «В проекте нет книг. Создайте книгу
   в списке.» — проект визуально «открывается», и автор сразу создаёт первую сцену.

## Последствия

- «Новый проект» и «Открыть проект» при уже открытом проекте не показывают ошибку
  «Сначала закройте текущий проект»: текущий проект сохраняется и закрывается сам.
- Только что созданный пустой проект открывается на карте книги, а не остаётся на лаунчере.
- Проект со сценами по-прежнему открывается сразу в редакторе.
- Если сохранить текущий проект не удалось, смена отменяется: старое состояние остаётся
  открытым, пользователь видит ошибку.

## Альтернативы

1. **Требовать ручного закрытия проекта.** Отклонено: лишний шаг и прежний источник ошибки.
2. **Открывать пустой проект в редакторе без сцены.** Отклонено: редактору нечего
   редактировать; карта книги — точка создания структуры.
3. **Оставлять пустой проект на лаунчере с сообщением.** Отклонено: пользователь считает,
   что проект не открылся; карта книги понятнее и сразу даёт следующий шаг.
