# ADR 034 — Обучение на экранах программы

Принято 2026-11-04 для версии 1.2.0 по прямому запросу пользователя.

В справку добавлена отдельная обучающая презентация из 12 уроков. Она использует
реальные снимки интерфейса ScriSelf Studio и палитру темы «Мокрый асфальт».
Сторонний макет редактора и сгенерированные изображения интерфейса не используются.

Текст уроков хранится в JSON, слайды PNG встроены как AvaloniaResource. Оглавление,
перелистывание, полноэкранный просмотр и текстовая расшифровка работают офлайн.
Окно не обращается к открытому проекту и не выполняет действия от имени ученика.
Задания предлагаются для отдельного учебного проекта. Грамматика описана с явным
ограничением русской пунктуации.

Редактируемая презентация собирается инструментом Presentations из того же JSON
и исходных снимков, затем проходит проверку структуры и визуальный просмотр.
В программу не добавляются PowerPoint, браузер или новая библиотека просмотра.
Исходники и воспроизведение: tools/build-training-presentation.mjs, tools/training/.
Модель данных книги и её схема не меняются.
