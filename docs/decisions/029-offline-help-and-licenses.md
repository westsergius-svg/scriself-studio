# ADR 029 — Встроенная справка и лицензии

Принято 2026-11-04 по запросу пользователя. Версия остаётся 1.1.13.

Справка открывается отдельным немодальным окном через F1 или «Справка».
Она не меняет навигацию и открытый проект. Повторный вызов активирует одно окно.
Контракт `IHelpService.Show(topicId)` находится в Contracts; Avalonia-реализация
в App, содержимое и поиск — в Presentation. Core не зависит от интерфейса.

Статьи и полные тексты лицензий встроены в сборку; сеть для чтения не нужна.
Поиск работает по заголовкам и тексту. Справка пока русская; оригиналы лицензий
сохранены на языке правообладателя. Номер версии берётся из сборки.

Пользователь явно выбрал MIT для собственного кода и документации. Copyright
использует существующее имя из Authors/Company — ScriSelf Studio. Отдельное личное
имя не назначалось. Сторонние компоненты и рукописи не перелицензируются.

Полные уведомления, карта зависимостей и руководство копируются в установщик.
Новые зависимости для чтения справки не добавляются. wiki-ru-wordnet и проверка
орфографии подключены по последующему запросу пользователя и описаны в ADR 030.
