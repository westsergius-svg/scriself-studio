# ADR 028 — Рабочее пространство «Мокрый асфальт»

Принято 2026-11-04 по явному запросу пользователя: использовать дизайн Photoshop
как ориентир для настольной писательской программы.
Название по уточнению пользователя — «Мокрый асфальт»; номер выпуска остаётся 1.1.13.

## Решение

- Используется существующее значение `AppTheme.Studio = 3`, без перенумерации enum.
  Тема «Мокрый асфальт» добавлена в переключатели и стала начальной темой новых настроек.
  Уже сохранённая поддерживаемая тема сохраняется при загрузке.
- Палитра — нейтральные графитовые поверхности, светлый текст интерфейса и синий
  акцент. Светлая страница рукописи отделена от тёмных инструментов.
- `StudioCommandBar` и `StudioToolRail` используют существующие команды оболочки.
  Меню «Проект», «Вид», «Панели» и вертикальная полоса разделов заменяют шапку
  классических тем. Не создаются отдельные дублирующие маршруты или состояния.
- Дерево книги показывается в редакторе; у карты, персонажей и линий используются
  собственные списки. Правый контекст сцены открыт по умолчанию. Существующее
  изменение ширины, скрытие панелей и режим «Холст» сохранены.
- Лист и переносы текста рисует штатный постраничный режим `AvaloniaRichEditor`.
  В теме «Мокрый асфальт» A4 вписывается в доступную ширину. Это оформление просмотра,
  не смена структуры документа или параметров экспортируемой книги.
- Фон панели форматирования изменяется через публичный `Content` компонента.
  Документ и команды остаются прежними; новые пакеты и отражение приватных API
  не используются.
- Системные размеры и шрифты панелей добавлены как ресурсы темы. В старых темах
  их значения восстанавливаются. Предпросмотр экспорта прокручивается внутри
  страницы, не перекрывая подпись внизу.
- По уточнению пользователя предпросмотр экспорта использует общий с записью файла
  `BuildManuscript` и `BuildOptions`. Текстовые форматы используют сам `TextExportWriter`;
  форматированные — абзацы из `ExportPreviewBuilder`, без редакторских меток сцен.
  Изменения параметров сразу обновляют превью. Пагинация не имитируется и её
  отличие от конечного файла явно указано; набор абзацев виртуализируется.

## Совместимость

Формат `.scri`, связи сцен/линий и контракты хранения не меняются. Четыре прежние
темы остаются в выборе. Настройка вкладок/меню сохраняет смысл для классических
тем; в теме «Мокрый асфальт» вместо неё используется фиксированная полоса инструментов,
что явно объяснено на экране настроек.

## Проверка

`StudioDesignTests` создаёт тестовую книгу, пишет текст, связывает сцены с линиями
и персонажами, открывает каждый экран через новые кнопки, проверяет компактное
окно и режим «Холст». Сохранение/восстановление темы включено в SettingsViewTests.
`ExportPreviewTests` переключает настоящие флажки и сравнивает превью с DOCX/TXT;
`ExportTests` проверяет включение/скрытие разделов во всех пяти форматах.
Визуальная приёмка проводится по снимкам и в настоящем Debug-окне отдельно
от автоматических тестов; итог фиксируется в TESTING.md.
