# ADR 033 — Локальные подсказки LanguageTool

Принято 2026-11-04. Этап 3 редактуры, приложение 1.1.13, схема книги 6.

## Контекст

Орфографию уже проверяет Hunspell. Нужны отдельные грамматические подсказки,
которые не отправляют рукопись в облако, не мешают вводу и не меняют текст сами.
Проверены официальный LanguageTool 6.6 и Temurin JRE 21.0.13+9 Windows x64.
Качество неполное: движок пропускает «Она сказала что придёт завтра» и
«Мне кажется что начался дождь». Нельзя обещать полноценную расстановку запятых.

## Решение

Отдельный IGrammarService в Contracts, реализация в Persistence. Java — дочерний
процесс приложения, только 127.0.0.1, случайный свободный порт, без --public,
CORS, verbose и облачного API. Проверка включается отдельно, по умолчанию выключена.
Архивы закреплены по версиям и SHA256; установка Java в систему не требуется.
Поставка сохраняет COPYING, third-party-licenses и legal целиком. Обычная сборка
не скачивает компоненты; подготовка и включение runtime — отдельный явный шаг.

Запросы ограничены по размеру, времени и очереди. Новый ввод отменяет старый
запрос; применение проверяет и ссылку на документ, и точный текст абзаца.
Автоязык выбирает русский/английский по преобладающему алфавиту абзаца; ручной
выбор хранится в настройках. Замечания не записываются в книгу и не экспортируются.
Исправление использует штатную замену редактора с оформлением и одним шагом Undo;
если включена запись правок, исправление попадает в неё.

## Последствия и альтернативы

При выключении или закрытии приложения дочерний процесс завершается. Отсутствие
runtime, ошибка запуска и таймаут показываются как недоступность проверки, а не
как отсутствие ошибок. Длинные абзацы проверяются частями; границы частей ограничивают
контекст. Словарные и стилистические замечания не дублируют существующие инструменты.

Локальная поставка существенно увеличивает размер приложения и требует памяти
Java. Облачный API не выбран: он меняет условия обработки рукописи. Самодельная
расстановка русских запятых не добавляется взамен пропущенных правил LanguageTool.
Публикация установщика и смена версии в этап не входят.
