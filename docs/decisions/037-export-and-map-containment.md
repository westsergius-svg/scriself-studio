# ADR 037. Оформленный PDF, компактный экспорт и виртуализация карты

Дата: 2026-11-17
Статус: принято; дополняет ADR 015 и 028

## Контекст

PDF сводил абзац к одной строке оформления и сбрасывал нумерацию элементов списка.
При 800×480 список форматов экспорта не прокручивался, отдельная панель предпросмотра
занимала место настроек. Карта строила все 500 карточек, а фиксированный холст по
высоте ограничивал длинную главу. Несколько пар цветов Starter/Studio не достигали
контраста 4.5:1 для обычного текста.

## Решение

1. PDF раскладывает оформленные фрагменты по строкам и страницам, сохраняя bold/italic,
   подчёркивание/зачёркивание и выравнивание. Счётчик нумерованного списка продолжается
   в соседних элементах и сбрасывается на обычном абзаце, другом списке и новой сцене.
   Длинные слова переносятся без пропуска графем; ресурсы layout освобождаются.
2. Список форматов экспорта занимает ограниченную строку Grid и владеет своей
   прокруткой. Названия/описания переносятся. При ширине ExportView ≤1000 отдельный
   предпросмотр и его разделитель скрыты, просмотр доступен в раскрываемой секции
   настроек. Оба представления используют один DataTemplate; кнопки переносятся.
3. Карта использует горизонтальный VirtualizingStackPanel для столбцов глав и
   ограниченный вертикальный ListBox сцен каждой главы. Шапки глав остаются над
   собственными списками. Кнопка добавления главы расположена над доской, вне её
   прокручиваемой ширины. Геометрия/масштаб из ADR 015 сохранены.
4. Синхронизируемый `SelectedScene` в столбце передаёт клавиатурный выбор штатной
   команде. Выделение по Guid переживает переработку контейнеров; открытие и команды
   структуры остаются в существующем ViewModel.
5. Затемнены второстепенные подписи Starter и акцентные фоны с белым текстом
   Starter/Studio. Все восемь проверенных пар достигли 4.5:1.

## Проверки и ограничения

`PdfExportTests` разбирает настоящие PDF; извлечённый текст и отрисованные страницы
дополнительно осмотрены. `CompactExportTests` проверяет пять тем при 800×480, мышь,
клавиатуру, предпросмотр, кнопку экспорта и возврат к широкой раскладке.
`MapVirtualizationTests` проверяет 1×500 и 25×20 сцен: ограниченное число контейнеров,
прокрутку, выделение и открытие. Измерения headless не являются Windows GPU/FPS.
Текущий журнал отделяет автоматические проверки от живого запуска и осмотра.
