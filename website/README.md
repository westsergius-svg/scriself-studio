# Статистика ScriSelf Studio и скачивание без VK

## Страница скачивания — обновление 2026-11-09

Последний опубликованный выпуск сохраняет карточку скачивания, SHA-256 и полное
описание. Предыдущие выпуски показаны компактным списком «Версия — Скачать — размер».
Адреса скачивания и счётчики сохраняются. Размер вычисляется по файлу установщика;
для внешних файлов используются сведения из записи версии. Новые публикации
автоматически перемещают прежний выпуск в список.

Файлы обновления: `modules/download.php`, `modules/download_presentation.php`,
`assets/css/download-archive.css`. Сначала загрузить вспомогательный PHP-файл и CSS,
затем шаблон. Перед заменой сохранить серверный шаблон и учесть его свежие правки.
Полную историю описаний по-прежнему можно открыть на `/changelog`.

Проверка отображения: `php website/tests/download_presentation_test.php`.

## Комплект статистики

Эта папка — обновление существующего сайта scriself.com. Это **не весь сайт**:
`config.php`, база, остальные страницы и пользовательские файлы остаются на месте.
VK полностью отключён; программа и опубликованные версии скачиваются без входа.
Старые ссылки `/vk/login`, `/vk/callback`, `/vk/logout` ведут на `/download`.
Вход в админку по-прежнему обязателен.

## Что появится

`/admin.php?action=app_statistics` — активные установки за сегодня, 7 и 30 дней,
число установок без сигналов за 30 дней, версии и платформы, график по дням,
начатые и полностью переданные загрузки за 30 дней и за всё время.

Источники скачиваний разделены: сайт, программа, прямая ссылка. Счётчик считает
повторные скачивания отдельно. Активная установка учитывается один раз за период.
Активность поступает из версии 1.1.12 после согласия пользователя. Отправляются
случайный номер профиля, версия и платформа; проекты и тексты не отправляются.
Старая статистика сайта в разделе «Версии» сохраняется.

## Публикация

1. Сохранить резервную копию заменяемых файлов **с сервера**. Файлы `admin.php`,
   `index.php`, шаблоны и JavaScript подготовлены по локальной копии сайта;
   если серверная версия отличается, перенести изменения с сохранением его правок.
2. Перенести файлы комплекта в соответствующие каталоги сайта. Не загружать
   `tests/`, `README.md`, тестовые базы и профили. Не заменять каталог сайта целиком.
   Сначала добавить `modules/app_statistics.php`, `modules/app_download.php`,
   `modules/admin_app_statistics.php`, `assets/css/app-statistics.css`,
   `app-activity.php`, `update-download.php`; затем обновить остальные страницы.
   `modules/vk.php` и `vk_config.php` из комплекта заменяют прежнюю интеграцию.
3. Загрузить установщик и соответствующий `latest.json` в `uploads/scrisoft/`.
   Затем установить подготовленный `uploads/scrisoft/.htaccess` с учётом
   дополнительных правил хостинга. Он направляет прежние ссылки обновлений
   через счётчик. Требуются Apache с mod_rewrite и разрешённым `.htaccess`.
   Если файлы отдаёт Nginx/CDN в обход Apache, этот маршрут нужно направить в PHP
   на стороне хостинга и исключить установщики/манифесты из кэша.
4. В админке, в разделе «Версии», добавить запись Windows 1.1.12
   с адресом `/uploads/scrisoft/ScriSelfStudio-Setup-1.1.12.exe`,
   размером и SHA-256 из комплекта. Если запись 1.1.12 уже есть, нажать «Изменить»:
   редактирование сохраняет её накопленный счётчик скачиваний.
   Прежнюю запись 1.1.11 и её счётчик сохранять отдельно.
   Отметка «Публичная версия» включает её на странице скачивания.
5. Открыть «Статистика». Таблицы `app_installations`, `app_activity_daily`,
   `app_download_daily` создаются автоматически. Нужны права CREATE, SELECT,
   INSERT и UPDATE в существующей базе. Каталог `cache/` должен быть доступен PHP
   для записи ограничителя запросов. Ошибка базы показывается как ошибка, не как ноль.
6. Проверить без входа `/download` и скачивание кнопкой, затем обновление из
   программы по прежней ссылке. В статистике появятся отдельные источники.
   Проверка HEAD не должна увеличивать счётчик. Файл должен совпасть с SHA-256
   комплекта. При CDN очистить прежние страницы с кнопками VK и манифесты из кэша.

Запрос активности: POST `application/json` на `/app-activity.php`, максимум 1024
байта; поля `installation_id` (UUID v4), `version`, `platform`. HTTP 204 — принято,
400/413/415 — некорректный запрос, 429 — ограничение частоты, 503 — временная ошибка.
Проверки обновлений не считаются скачиваниями. Готовность сервера отдать файл
не является подтверждением установки программы на компьютере.

Номер сборки — **1.1.12**. После публикации установщика и нового `latest.json`
прежняя 1.1.11 обнаружит обновление обычной проверкой. Обновить SHA-256 записи
в админке и очистить кэш манифеста на хостинге/CDN.

Для отката вернуть сохранённые файлы сайта. Таблицы можно оставить: они не меняют
прежние данные. Не следует возвращать активную VK-интеграцию при частичном откате.

## Автоматическая проверка

PHP 8.2+ с `pdo_mysql` и отдельный локальный MySQL/MariaDB. Сценарий создаёт и удаляет
собственную базу с уникальным именем, не использует настройки рабочего сайта.
Пример PowerShell для временного сервера на порту 33316:

```powershell
$env:SCRISELF_STATS_TEST_SERVER_DSN = 'mysql:host=127.0.0.1;port=33316;charset=utf8mb4'
php -d extension=pdo_mysql website/tests/statistics_test.php
```

При необходимости задать `SCRISELF_STATS_TEST_USER`, `SCRISELF_STATS_TEST_PASSWORD`
и каталог PHP-расширений через `-d extension_dir=...`. Стенд подменяет только
существующую авторизацию администратора; интеграция VK в нём отсутствует.
Встроенный сервер PHP моделирует перенаправление ссылок, но не проверяет Apache.
Логи и копии стенда сохраняются в `artifacts/usage-statistics/`.
