# Изолированный стенд первого запуска

Стенд рисует реальный AXAML ScriSelf Studio через Skia и передаёт указатель,
клавиатуру и ввод текста в Avalonia.Headless. Это проверка интерфейса приложения,
а не управление живым окном Windows. Проекты записываются настоящим SQLite-хранилищем.
Каждая сессия получает отдельные настройки и файлы внутри `qa/first-users/`.

Инструкция для участника — [DRIVER.md](DRIVER.md). Текущий отчёт версии 1.2.0 —
[методика и материалы](../../qa/first-users/20261104-1.2.0/README.md).

```powershell
dotnet run --project tools/FirstUsersQa --configuration Release -- qa/first-users 38461
```

API слушает только `http://127.0.0.1:38461/`. Запросы выполняются последовательно.
Нельзя использовать сервер одновременно нескольким агентам.

```powershell
$qaBody = @{ op = 'reset'; session = 'trial-impatient'; width = 1440; height = 900 } | ConvertTo-Json
Invoke-RestMethod -Uri http://127.0.0.1:38461/ -Method Post -ContentType 'application/json; charset=utf-8' -Body ([Text.Encoding]::UTF8.GetBytes($qaBody)) | ConvertTo-Json -Depth 8
```

Каждый ответ содержит путь PNG, видимые подписи, координаты элементов, текущее
число кликов и ограничения стенда. Просматривайте PNG через `view_image`. Номера
`target` действительны только для последнего ответа. Можно нажать по координатам.

Операции:

- `reset`: `session` (новое имя, буквы/цифры/дефисы), `width`, `height`. Существующие сессии не перезаписывает.
- `observe`: обновить кадр; `waitMs` от 50 до 3000 для ожидания фоновой операции.
- `click`: `target` либо `x`, `y`; `count: 2` для двойного клика; `button: Right` для контекстного меню.
- `move`: `target` либо `x`, `y`, например для всплывающей подсказки.
- `type`: `text`, ввод в уже сфокусированное поле.
- `key`: `key` (например `A`, `S`, `Escape`, `Enter`, `Tab`), `modifiers` (`Control`, `Shift` либо `Control, Shift`).
- `scroll`: `x`, `y`, `delta` (обычно `-3` вниз).
- `resize`: `width`, `height` в логических единицах Avalonia.
- `picker`: настроить **следующий** выбор файла: `fileName` без каталога либо `cancel: true`.
- `restart`: закрыть приложение с его штатным сохранением ожидающих правок и открыть с теми же настройками. Проект затем открывается через интерфейс.
- `closewindow`: закрыть переднее дополнительное окно, например справку.

Без настройки `picker` новый проект получает предлагаемое приложением имя;
открытие выбирает последний `.scri` в текущей тестовой папке. Выбор файла и
перезапуск не входят в число кликов внутри приложения. Диалоги названия,
подтверждения и ошибок — настоящие окна приложения; следующий запрос адресуется
активному модальному окну. При модальном окне ответ содержит также PNG основного окна.
Если первое нажатие закрывает диалог, второе ему не отправляется; ответ сообщает
об этом, а счётчик учитывает только доставленные нажатия. Перед переходом между
окнами стенд передаёт уход указателя из предыдущего окна.

Не покрываются: системные файловые диалоги, рамка окна и физический DPI Windows,
реальная сеть/3G, браузер, Проводник, OAuth и платежи. Обновления и облако заменены
службами без сети; их ответы нельзя считать дефектами продукта. В проверке 1.2.0
основной размер — 1440×900. Компактные участники сначала запросили 375×812,
получили фактические 800×812 и прошли основной путь при 1024×768.
Это логические размеры Avalonia, не проверка телефона или физического DPI.

История запросов хранится в `actions.jsonl`, кадры и наблюдения — в каталоге сессии.
Ответы содержат точные пути снимков. Тестировщики не должны читать исходники,
результаты других тестировщиков или изменять файлы продукта.

`verify_saved_projects.py` независимо читает сохранённые SQLite-файлы и сверяет
текст с `assessment.json`. `Build-Report.ps1` собирает HTML из готового `findings.json`.
